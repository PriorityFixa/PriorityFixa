# PriorityFixa Agency — One Page Website

A polished, responsive agency landing page inspired by modern creative-agency layouts.

## Stack
- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts: Syne + DM Sans
- Font Awesome icons

## Main sections
- Hero
- Trust / client logos
- Services
- Process
- Featured case study
- Why PriorityFixa
- Client logos
- Contact CTA
- Footer

## Quick start

Open `index.html` in a browser.

For local development, you can also use VS Code Live Server.

## Important customisations

Replace:
- `hello@priorityfixa.com`
- `+254 700 123 456`
- social media `#` links
- placeholder client names/logos
- Empowered Teachers Forum project details
- case study metrics

with your real business information.
